# サイトD — GitHub Pages 公開用（v4.11D.8）

従来のD.8デザイン・操作を維持した静的フロントエンドです。
サイトC（uoxou910/no__pri）とは**別のリポジトリ**に置いてください。

## GitHub Pages

1. GitHubの「New repository」で `site-d`（任意の名前）を作成します。
2. **このフォルダの中身**（`index.html`、`edit.html`、`assets/` など）をリポジトリのルートにアップロードします。
3. Settings → Pages → Build and deployment → Deploy from a branch。
4. Branch `main`、Folder `/(root)` を選び保存。
5. ユーザー名が `uoxou910`、リポジトリ名が `site-d` なら
   `https://uoxou910.github.io/site-d/` に公開されます。

## 大切なこと：GASは別途必要

GitHub PagesはHTML/CSS/JSを表示できますが、データベースや安全な管理者認証は提供しません。

- `assets/config.js` の `gasUrl` に**自分の**GASウェブアプリURLを設定します。
- GAS側のスプレッドシートID、パスワードのハッシュ・ソルトは**GASのScript Properties**に設定してください。
- **パスワード、生パスワードの埋め込まれたGASコード、個人情報はGitHubへアップロードしないでください。**
- GAS URL未設定で公開URLを開くと、公開データは未読込となり、管理画面は「準備中」と表示します。
- `file://`（ローカルファイル）では従来のローカルデモを利用できます。
- ローカルデモのデータは自動的には公開サイトに移行されません。
- GAS接続時、フレカ画像の登録は現行コードではURL指定方式です。
  ローカルデモと同じ複数画像の直接アップロードは未実装です。
- 同梱のGASは接続試験前の試作コードです。公開前に認証の試行制限、
  GoogleのCORS／リダイレクト挙動、長いパスフレーズなどの検証が必要です。
